# Es2API v2026.11.04-preview.4

本版补齐 OAuth 导入时的身份和到期时间传递，并收紧嵌套记录的选择范围。

## 修改内容

- 控制面和执行面共用 OAuth 记录选择器：单次导入只取一条记录，不从兄弟对象或其他账号补齐 access/refresh/id token。
- 保留同一记录的 ChatGPT 账号 ID、邮箱和绝对期限；秒、毫秒、带时区 ISO 文本统一为 Unix 秒。元数据只取自选中记录及透明包装层。
- accounts/documents 集合外层信息不传递到账号，跳过非 OpenAI/Codex 文档；管理记录 ID 不作为供应商账号 ID。
- 公开凭据摘要保持白名单，令牌指纹算法不变；现有账号、配置和数据库记录不做迁移。详细规则见[集成契约](../integration/CONTRACT.md)。

## Linux 分发与检查范围

附件为 `Es2API-linux-x64-20261104-r4.tar.gz` 及 `.sha256`。按[Linux文档](../deploy-linux/README.md)备份后升级；保留账号数据、固定出口与加密密钥。

本版仅修改 Node 导入层和文档，沿用 r3 前端、两平台 Go 产物与固定 CLI。语法、模块依赖和包内容检查不等于真实认证证明；本轮不运行测试、新账号导入、现有账号迁移、真实推理、Linux安装或浏览器验收。真实 CLI→API、取消、用量、跨账号隔离、长输入及 ModelTrace 历史502仍待独立验收。稳定供应商身份去重尚未实现，OAuth 刷新后的令牌指纹仍可能改变。
