# Es2API v2026.11.06-preview.31

## 账号归属与独占 IP 持久化

- 生命周期要求完整、匹配的账号归属和正安全整数代次，防止接管元数据不完整的历史槽位。
- 代理池在同一 SQLite 事务中比较原数据快照并一起保存绑定和配置。冲突拒绝覆盖，失败后重读；没有自动重试旧分配。
- 探测和地理结果先完整收集，等待后核对快照；停用、恢复调度、断开回调在保存成功后执行。配置补丁先全部校验。
- 旧 JSON 导入也使用快照接口；数据库/配置读取失败不再用空池覆盖。无数据库结构迁移。

详见 [槽位归属](SLOT_BINDING_VALIDATION.md) 与 [并发持久化](PROXY_POOL_CONCURRENCY.md)。Linux 包包含上轮已发布但未打包的归属修复。

## 范围与证据

主程序、前端、Node、Codex CLI 和 Kernel 沿用 r30，不重新编译。此次更新可独立加载的 integration/VM2 源码和文档。仅源码审查、语法/模块加载、只读状态/健康及归档发布核对；没有测试套件、真实代理分配、故障注入、并发、Linux安装或UI行为验收。

没有手动调用网络诊断、模型、OAuth 换票或真实凭据恢复。产品原有代理自动监控配置保留，服务启动或定时器可能进行既有常规 SOCKS 健康检查；这不代表专用 DNS/TLS 诊断已经执行或获准。

多进程必须统一升级；不同数据库的集群分配、VM文件/容器的跨进程协调以及提交后回调的崩溃一致性仍待完成。独占代理资源不等于已验证的独占公网IP。真实 gpt-6-luna 最近仍 HTTP502/codex_cli_connection_failed，无有效正文/usage；真实 CLI→API 尚未跑通。HTTPS 暂缓。

Linux包：Es2API-linux-x64-20261106-r31.tar.gz 及 .sha256，不包含用户 runtime、数据库或私密日志。
