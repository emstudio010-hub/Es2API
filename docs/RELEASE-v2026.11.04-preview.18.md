# Es2API v2026.11.04-preview.18

本版补WebSocket发送背压、保活与连接收尾。

## 修改内容

- 共用WS发送器逐帧发送，计入当前帧/排队帧和bufferedAmount，单帧10MiB、待发送16MiB/256帧，从入队起30秒本地发送期限；超限、写错或关闭清理回调/等待者，不重放或重试。
- 网关下游发送量达到256KiB时暂停上游读取，回落64KiB再恢复；不暂停客户中断输入。每轮上游输出累计64MiB/262144帧，原有单轮租约、身份归属和取消不成功计数保留。
- VM2的HTTP→WS适配使用真正Writable，64KiB高水位及16MiB硬缓冲上限，SSE写入等待WS本地发送回调；收尾等待Writable和发送队列完成，再记连接内重放快照/运行下一轮。
- SSE→WS桥接连续UTF8解码，限制每轮64MiB、单行/事件8MiB、262144行、待转换256帧/16MiB；JSON错误体8MiB。成功终态核对响应ID、completed状态和output数组，矛盾/重复终态明确关闭，不用单独类型字符串冒充成功。
- 网关两端及VM2下游增加协议ping/pong，15秒发随机nonce，45秒未收到匹配pong关闭；背压暂停读取时不误判未处理pong，仍由30秒发送期限兜底。不向模型JSON添加keepalive或成功事件。
- 断连/发送失败终止WS并取消当前请求，清空输入队列；VM2中断后的连接不再复用，最多10秒关闭。interrupt.accepted、本地发送回调或租约归还仍不证明实际执行排空。

详见 [Codex CLI后端及协议](CODEX_CLI_BACKEND.md)。发送回调仅表示本机WS已写出；不等于远端收到、模型完成或容器退出。固定阈值会拒绝超大合法帧，累计线量包含元数据和重复终态。接收和发送仍由ws库及TCP处理；不是精确heap上限或独立虚拟机隔离证明。
