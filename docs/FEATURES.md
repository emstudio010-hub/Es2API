# 相对 VM2API / Sub2API 增加了什么

## 2026.11.04 增量

- 账号管理导入 OAuth 后建立独立账号池工作区，集中管理实例、固定 IP、运行设置和发布。
- 默认自动分配空闲独占代理，创建时可以手选；时区未知或无资源时失败关闭，绑定后不自动切换。
- 可选真实 Codex CLI 文本执行后端，单并发、请求目录隔离、短期认证副本、串行刷新和进程组取消；详见 [CLI 能力与边界](CODEX_CLI_BACKEND.md)。
- 工作区启动、停止、恢复采用后台操作与状态刷新；保留手动暂停。CLI 恢复仅在容器停止得到确认后清理残留请求。
- 停机、删除均再次核对 Docker 状态；删除未确认时保留记录、凭据和固定出口。

## 一、产品整合

VM2API 继续负责执行槽、容器和供应商执行；Sub2API 继续负责原生账号、用户、分组、服务 Key、余额和计费。Es2API 新增 integration，将这两部分以服务端认证和显式契约连接。前端只增加必要入口，未把两套后台机械拼成同一个登录页。

| 原有能力 | Es2API 增量 | 主要实现 |
| --- | --- | --- |
| VM2 槽与容器 | 账号池生命周期、规范槽ID、归属/代次检查 | `integration/src/lifecycle.mjs`、`contract.mjs` |
| 固定出口与身份配置 | 账号导入时选出口，后续不提供编辑出口接口 | 同上及 VM2 panel 适配 |
| Sub2API 用户/分组/Key | 账号池发布到原生 OpenAI 分组 | `sub2api/backend/internal/handler/admin/integration_publish.go` |
| 原生协议入口 | 加入私有池网关、调用者命名空间及租约 | `integration/src/gateway*.mjs` |
| 原管理页面 | 新增账号池、ModelTrace 与隔离详情 | `sub2api/frontend/src/views/admin/` |

## 二、账号池与 OAuth

- 共享和租赁账号模式；不同模式的自动检测启用规则显式配置。
- JSON 凭据导入、浏览器 OAuth 授权与 state 校验；授权码兑换后进入账号池。
- 分组、权重、暂停/恢复、并发上限、失败状态、槽状态同步和重试。
- 凭据在 integration 的 SQLite 中加密存储；管理响应只返回存在性、指纹与脱敏信息。
- 删除账号前确认执行槽已经移除，避免先丢失本地凭据而留下失管实例。
- 管理员可查看账号绑定、创建代次、时区、容器与隔离状态；未返回的状态不伪造为“正常”。

## 三、生命周期与固定环境

创建过程为：建立账号记录 → 创建空槽并选择出口 → 导入 OAuth → 启动 → 读取健康状态。失败状态会保留，以支持沿原账号重试。槽位重建会增加 `provision_generation`。

槽名规范为 `es2-${accountId}`。创建响应、已有槽重试、同步、就绪和删除前均检查绑定。带有 integration 标记的槽还要核对所属账号和代次。返回陌生槽时，不导入凭据、不启动也不删除它。

时区及身份配置随创建时的出口派生，不能据公网 IP 推出“唯一、物理真实或不可关联”的设备身份。账号池不支持运行中修改 IP；更换出口需要重新创建账号/槽。

## 四、用户调用发布

管理员可以把账号池分组发布到已有原生 OpenAI 用户分组。公开客户端使用原生用户 Key；Sub2API 完成认证、额度、权限及计费，再由私有网关获得账号租约并执行请求。

发布不是自动发生的，用户必须选择分组。原生直连账号也不会自动迁入新池。管理令牌轮换后，已发布的派生凭据需要按集成说明更新。

## 五、账号与会话隔离

| 边界 | 机制 |
| --- | --- |
| 不同用户 Key | Go 控制面从已认证 Key 的数据库ID派生 HMAC 标识，不信任客户端内部头 |
| 不同分组 | caller 与分组共同构成 scope，不能跨组续接 |
| 同一会话 | 首次选槽和租约同事务固定账号，后续使用绑定账号 |
| 响应/输出项引用 | `previous_response_id`、`item_reference` 要求当前 scope 已观测并拥有该资源 |
| 槽重建/同名账号再导入 | 代次与账号实例加入归属，不继承旧实例资源 |
| 出站缓存/会话 | session、conversation、thread、prompt_cache 标识加入私有命名空间 |
| WebSocket | 逐帧 JSON 桥接，首个 `response.create` 选槽，一连接一租约 |

响应索引保存哈希与归属，TTL 为 24 小时，总量上限 200000；不保存提示词和回答正文。绑定账号不可用、满并发、暂停或迁组后返回错误，不静默换到另一账号续接。

WebSocket 限制：首帧/握手 15 秒、空闲 15 分钟、帧 10 MB、积压 8 MB。未知控制帧和二进制帧拒绝，连接关闭释放租约，不自动重试推理。

这些是代码实施的边界。新版本未做跨账号、并发、流式或真实供应商验收；管理员/master 权限仍能执行原有管理操作，Docker 共享宿主内核，共用代理时公网 IP 也可能相同。

## 六、模型检测

新增独立控制台、固定参考库、按账号覆盖、自动调度、取消、历史和动作策略。详情见 [MODELTRACE.md](MODELTRACE.md)。自动触发方式与指纹算法是两个概念：增加触发方式不代表增加了同样数量的独立模型识别算法。

## 七、运维与界面

- 成功调用通知以持久事件拉取，避免 Windows/WSL 反向回调问题；事件去重后进入用量和检测进度。
- Windows 计划任务守护本机三服务；本地维护工具提供备份/恢复/程序回滚。
- Linux 分发启动器使用新随机密钥、独立运行目录、本项目数据库 Compose 与 systemd；内部端口默认回环。
- 鎏金主题调整主色、导航、按钮、明暗画布与层级；新增图标和品牌默认值。
- 新增空态入口、键盘导航、对话框焦点、减少动态效果与移动视口适配。

未提供已完成的 HTTPS、生产监控体系、完整物理虚拟机隔离或供应商长期可用性保证。
