# Es2API v2026.11.04-preview

本版继续基于 VM2API 衍生分支，整合 Sub2API 控制面；保留两个上游的归属和许可。它是功能预览，不表示正式生产验收完成。

## 一账号一工作区

- 将 OAuth 账号管理与账号池入口分离。新导入的每个 OAuth 建立独立账号池工作区，集中管理执行实例、固定 IP、运行设置与发布入口。
- 默认自动分配空闲独占代理，也可在创建时手选。时区随所选出口获取，再生成对应环境配置；缺少资源或时区时停止创建，不回退直连。
- 绑定后不自动更换出口；重启和同账号重建保留固定代理。已有账号、凭据与分组不自动迁移。
- 独占的是代理资源记录，不保证不同资源对应不同公网 IP；Docker 共享宿主内核，不等同独立虚拟机。

## 真实 Codex CLI 执行后端（预览）

- 导入时可选 Kernel 或 Codex CLI；现有账号保留原后端。CLI 固定版本 0.155.1，单账号并发为 1。
- 在本账号 Docker 容器内运行真实 `codex exec --json --ephemeral`，将 JSONL 输出适配为 Responses 或 Chat Completions，支持纯文本流式/非流式请求。
- 每请求独立 HOME/CODEX_HOME/工作目录，固定工具只读挂载；read-only 沙箱、禁用工具/插件/MCP/网页搜索等能力。
- 临时认证副本不包含 refresh token，控制面经固定出口串行刷新。增加进程组取消、心跳、5分钟总限、输入/输出大小限制。
- CLI 为消息完成后输出文本事件，并非逐 token 直通；多轮以文本对话记录输入，不等价于原生角色消息。工具、图片、结构化输出、输出 token 上限、temperature、tier/fast/priority 和 response ID 续接目前明确拒绝。
- 分发包附 CLI、bwrap、许可证与对应 bubblewrap 源码；源码 Git 不提交这些工具二进制。

## 实例运维与数据保留

- 工作区新增启动、停止、恢复操作，返回 HTTP202 后在后台处理，页面自动刷新状态。
- 操作前暂停调度；完成后仍保持暂停，由管理员检查后手动开启。同步状态也保留手动暂停。
- CLI 恢复先取消在途执行并确认容器完全停止，再清理本账号残留请求目录；不能确认停止时拒绝清理。恢复期间拒绝冲突的启动、重载和删除。
- Docker 停机和删除增加结果确认；容器删除未确认时保留账号记录、凭据与固定出口。
- 修复 CLI 后端账号重建/删除时绑定信息缺失的问题。
