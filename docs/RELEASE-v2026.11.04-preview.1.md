# Es2API v2026.11.04-preview.1

这是对上一预览版的CLI执行修订，保留一账号一工作区、固定出口与已有账号的原后端。

## 修复内容

- **就绪状态**：统一健康检查和调用准备的令牌期限判断。支持秒、毫秒、ISO和JWT期限；访问令牌期限不足或未知且无刷新令牌时，给出需要重新导入完整OAuth的提示。
- **执行预算**：认证准备计入五分钟执行预算，容器CLI只获得剩余时间。取消或预算耗尽后不会继续启动推理；刷新已开始时仍保存成功轮转的凭据，避免丢失刷新令牌。
- **失败用量**：最终输出交付异常时保留已经收到的真实用量和首条文本时间，失败日志继续标记失败，不计为ModelTrace成功调用。没有收到的用量不估算。
- **数量与清理**：拒绝非法缓存/推理token计数及超出安全整数范围的总计数。已完成请求清理失败不再覆盖执行结果；下次调用无法清理时拒绝启动新请求。

## 安装与范围

Linux文件为 `Es2API-linux-x64-20261104-r1.tar.gz`，对应`.sha256`同时提供。请核对附件校验文件，按[Linux运维说明](../deploy-linux/README.md)备份并升级，不覆盖账号、数据库或加密密钥。

本修订仅修改Node执行层与文档/打包版本；Go和前端编译产物沿用上一版已经构建的同一份程序。本次完成源码语法、模块加载及分发文件核对，没有运行测试套件或真实供应商推理。Linux部署、真实OAuth执行、取消/用量及跨账号隔离仍未验收。完整新增功能见[上一版说明](RELEASE-v2026.11.04-preview.md)，CLI范围见[能力与边界](CODEX_CLI_BACKEND.md)。
