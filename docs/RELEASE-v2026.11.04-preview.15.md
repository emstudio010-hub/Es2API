# Es2API v2026.11.04-preview.15

本版补齐 Codex 排队与实例就绪阶段的 SSE 保活及失败收尾。

## 修改内容

- Codex 流式请求在排队、账号权限检查和 CLI/Kernel 就绪阶段复用请求级保活；共享排队延迟与间隔配置，非流式不发送 SSE。
- 保活提交 200 后的准入、权限和就绪失败使用协议错误帧收尾，保留真实 status、错误内容与重试秒数；不重复写 HTTP 头，不生成成功终止事件。快速失败仍保留原 HTTP JSON 状态。
- 保活遇到下游背压跳过追加，断开与所有出口清理计时器；就绪检查返回后再次核对取消，不启动已取消请求的推理。
- 内部传输重试、历史回退和同账号延迟重试均再次核对下游是否已提交，提交后不再重试；CLI 与 ModelTrace 继续单次尝试。
- 账号权限检查抛异常时也归还已领取执行租约。

详见 [Codex CLI 后端](CODEX_CLI_BACKEND.md)。现有账号继续使用 Kernel，未迁移 CLI；未改变账号、IP、凭据、工作区设置、DB 结构或指纹算法。前端、Go、Kernel 和固定 CLI 二进制沿 r14。

## 分发与验收

附件为 Es2API-linux-x64-20261104-r15.tar.gz 与 .sha256。本版只做语法、模块加载、源码/依赖/许可/哈希核对和只读健康清点；按用户要求不运行测试，也不做真实推理、OAuth 刷新、账号导入/迁移、实例生命周期、浏览器或 Linux 安装验收。

保活只表示 HTTP 通道仍有字节，不证明上游有进度、执行已退出、用量正确或账号隔离通过。已经提交的 HTTP 200 无法改成 403/429/503，调用方须检查 SSE 错误内容；[DONE] 仅结束 Chat 流，不表示成功。WS 桥接可能丢弃 SSE 注释，本版不证明 WebSocket 连接保活。慢消费者只抑制额外保活，未重写真实输出的背压管线。真实 CLI→API、取消/超时/退出回执、跨账号隔离、ModelTrace 历史第三样本 502、Linux 完整安装仍未闭环，HTTPS 暂缓。
