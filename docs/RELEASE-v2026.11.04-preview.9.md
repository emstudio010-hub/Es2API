# Es2API v2026.11.04-preview.9

本版修补 CLI 执行失败、取消、超时和非流式请求的收尾。

## 修改内容

- CLI 取消/交付失败后仍观察已产生的有效 turn.completed 用量；不把失败变成完成，缺少缓存 token 数量时不填零。
- 异常和普通失败共用一次终止事件回传，保留原错误码；客户端已断开时只收尾，不重复发送完成或失败。
- 容器监督器按毫秒接收剩余预算，记录超时/取消/心跳丢失的固定原因；超时映射504、取消映射499，异常原因拒绝成功。
- 非流式缓冲中的事件不再冒充已发送响应；CLI 产生部分文本后失败仍返回结构化错误和对应状态。

详见 [Codex CLI 后端](CODEX_CLI_BACKEND.md)。不改变固定独占出口或已有账号后端，不自动重试推理。

## 分发与验收

Linux 附件为 `Es2API-linux-x64-20261104-r9.tar.gz` 和 `.sha256`，参照 [Linux 说明](../deploy-linux/README.md) 备份后升级。沿用 r8 前端/Go/Kernel 和固定 CLI。

仅 Node 语法/模块加载、内嵌 Python 监督器 AST、源码/包核对与只读健康清点；不运行测试或真实账号推理、刷新、导入、实例生命周期、Linux 安装和浏览器验收。真实 CLI→API、取消/超时、跨账号隔离、长输入和 ModelTrace 历史502仍未验收。
