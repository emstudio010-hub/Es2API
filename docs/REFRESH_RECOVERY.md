# Codex 宿主刷新日志与恢复

## 处理顺序

CLI、目录/配额/搜索使用的宿主刷新及管理员刷新统一进入 `refreshStoredCodexCredential`。先取得槽控制锁、排空 Kernel 请求并确认 Kernel 退出，再读取完整凭据快照。刷新前核对旧凭据的历史签名身份；不按邮箱或共享 workspace 提示选择另一条记录。

1. 在项目运行根的 `.codex-refresh/<vm-id>.pending.json` 保存换票意图：完整旧记录、选中索引、已签名身份哈希、槽归属/代次/后端/代理摘要。
2. 意图保存并同步成功后才向固定 OAuth 端点请求一次换票，不跟随重定向。没有可用加密密钥或存储即停止；不回退明文。
3. 收到包含 token 的响应后，先加密保存响应中的 access/refresh/ID 与绝对期限，再判断状态、验签或提交。非成功响应若携带新 token 也保留；不保存供应商原始错误正文。
4. 核对新 access/ID 的签名和旧版固定 client 身份；用户与 workspace 的身份哈希必须与换票前一致。随后比较完整旧记录或已经写入的完整目标记录，以及槽归属摘要。
5. 只在检查通过后写入凭据，重新读回核对，文件及目录同步成功后才将 pending 日志移为带操作 UUID 的 `.resolved.json` 加密历史。历史保留，不能作为缓存清理。

日志使用 AES-256-GCM，密钥由至少32字符的 `VM2API_DB_SECRET`（兼容 `KIN_DB_SECRET`）作域分离派生；AAD绑定版本、槽ID和操作UUID。目录0700、文件0600，不接入公开摘要、请求日志或发布附件。必须使用本机 Linux 目录同步；不支持的平台在换票前拒绝。

## 未确认状态

pending 跨进程重启保留。正常凭据读取、刷新、CLI/Kernel启动、凭据覆盖/清除、checkpoint与删除会拒绝；管理摘要仍可读，增加 `credential_refresh_pending` 布尔字段。允许停止实例；停止后恢复不会解除停止标记，需随后显式启动。

本机管理员可调用 `POST /api/panel/vms/:id/oauth/recover`。该入口仍取得同一控制锁并排空/停止 Kernel，只读取已加密保存的响应，重新验签及比较后提交或确认已经完成的提交；**不再次请求 OAuth，不调用模型**。验签可能只获取公开 JWKS。响应仅返回 recovered 与 oauth_exchange_performed=false，不返回 token、日志正文或磁盘路径。

如果日志只有 prepared 意图，或者响应不完整、供应商返回错误、账号不符、旧凭据/槽归属变化、密钥/磁盘/JWKS不可用，恢复拒绝且原记录和日志保留。网络超时不能证明供应商未轮转；不能清掉意图后再消费旧 refresh token。此类情况需要管理员结合原加密备份、供应商重新授权与专门的凭据处置流程处理；本版没有自动丢弃/接受不明结果或强行解锁的入口。

## 备份与回滚

必须同时保存完整运行目录、加密密钥、`.codex-refresh`、integration数据库、实例凭据及数据库导出。日志位于槽目录之外，删除一个槽也不能让它丢失。Windows本地 operations 备份包含 codex-refresh，恢复前发现当前 pending 会拒绝，以免旧数据库/密钥覆盖未确认的新令牌；历史及新旧快照保留。Linux部署应停止服务后备份完整 runtime。

有 pending 时不要降级到不识别日志的旧版本，不手动删除/重命名日志、轮换加密主密钥、覆盖凭据或清理其目录。磁盘已满、权限错误、主机断电或供应商响应尚未到达本机时，日志只能阻止危险重试，不能凭空恢复尚未持久化的令牌。文件/目录 fsync、断电恢复及 Windows挂载目录的真实语义尚未验收。

## 保证范围

仅覆盖 Es2API 宿主主动换票流程。临时 Codex CLI 请求副本仍不含 refresh token；第三方预编译 Codex Kernel 运行时仍可能自行刷新，其内部逻辑不受本日志包裹。普通只读目录/配额/搜索的已有出站请求也不是全部纳入了同一文件活动锁，不能把新增读取门禁宣称为所有网络在途操作的原子隔离。

旧槽只含 refresh token 时，导入入口拒绝并要求完整可验签凭据，不再自动消费一个未知账号的 RT。非 stale 重试增加控制面历史签名与原身份索引核对，但不代表远端 Kernel 的全生命周期身份锁已完成。

本版按用户要求没有运行测试、真实刷新、恢复、故障注入或模型调用。语法/模块加载、只读健康和打包检查不能证明并发、网络失败、令牌轮转、崩溃或恢复正确性；真实 CLI→API 成功正文/usage 仍未取得。
