# Es2API v2026.11.04-preview.7

本版补齐本机 Codex 实例停止和删除时的进程退出确认，避免只移除容器就释放账号数据和固定出口。

## 修改内容

- 显式停止/删除和禁用出口前持久记录操作意图，阻止重新调度、刷新或启动；失败后跨控制进程重启保留，可重试原操作。
- 取消CLI并确认分离宿主Kernel退出、Docker停止/移除、内部流和宿主CLI请求释放后才返回成功。删除成功之后才清理目录并释放出口。
- 已确认停止可从账号池显式启动，未确认停止及待删除状态拒绝开机。恢复实例复用退出确认后再启动；凭据交接复用已有锁，避免嵌套等待。
- 旧执行槽reset/清空/覆盖OAuth入口拒绝独立账号池托管实例；生命周期仍可按预期绑定if_missing导入，避免绕过工作区归属和凭据交接。
- 同UID进程命令行不可读取时拒绝确认Kernel退出，不把进程跟踪表为空当作退出证据。

详见[凭据与生命周期](CREDENTIAL_CONTINUITY.md)。本机单控制面范围；没有自动停止、迁移、重建或重新导入现有账号。

## 分发与验收

Linux附件为 `Es2API-linux-x64-20261104-r7.tar.gz` 和 `.sha256`，按[Linux说明](../deploy-linux/README.md)备份后升级。沿用r6前端/Go/Kernel及固定CLI。

仅语法、模块加载、源码/分发核对和只读健康清点；没有测试、真实停机/删除/恢复、刷新/交接、推理、Linux安装或浏览器验收。崩溃/并发/退出超时与真实CLI→API、用量、取消、跨账号隔离及ModelTrace历史502仍未验收。
