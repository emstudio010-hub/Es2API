# Es2API v2026.11.04-preview.5

本版修补 OAuth 刷新后的生命周期连续性，避免重试或修改设置重建时重新写入旧令牌。

## 修改内容

- 重试核对槽归属、代次、后端与出口；有唯一可用 OAuth 记录时保留，不覆盖已轮转的令牌。损坏文件不按空槽处理。
- 重建前持久冻结，确认 Docker 容器和宿主分离 Kernel 退出，再交接当前凭据。控制面以账号/槽/代次/旧指纹比较条件，在一个事务内加密保存新凭据和回执，提交后才删除旧槽。
- 交接失败保留旧槽、凭据和固定出口；冻结状态跨重启保留，阻止启动、刷新、重导入、清除和 reset。交接回执支持删除已完成但映射尚未提交的中断重试。
- 宿主侧目录、配额、搜索、管理及 CLI 刷新共用账号槽锁，写入前重新核对原记录。管理员内部凭据交接响应设为 no-store，不加入公开摘要。详细规则见[凭据连续性](CREDENTIAL_CONTINUITY.md)。

## 分发和边界

Linux 附件为 `Es2API-linux-x64-20261104-r5.tar.gz` 和 `.sha256`；按[Linux说明](../deploy-linux/README.md)备份后升级。交接支持本机 Linux Docker Codex 槽，其他运行时明确拒绝。

本版沿用 r4 前端、Go 产物和固定 CLI。没有自动刷新、迁移或重建现有账号；没有执行测试、真实刷新/交接/重建、推理、Linux安装或浏览器验收。Kernel 普通运行时与宿主刷新仍有跨进程协调边界，稳定供应商身份去重未实现。真实 CLI→API、用量、取消、隔离和 ModelTrace 历史502仍未验收。
