# Es2API v2026.11.04-preview.2

本版补充 ModelTrace 响应完成校验与失败诊断，保留上一版 CLI 执行修订及一账号一工作区机制。

## 新增与修复

- 检测过程中保存样本进度；失败明确记录停止样本、HTTP 状态、耗时、时限和允许的连接错误类别。控制台使用可读提示，技术信息可展开查看。
- JSON/SSE 必须明确完成，失败、未完成、拒答、空文本和格式异常不再被当作有效指纹样本。响应最多读取 4 MiB，不读取 HTTP 错误正文，不保存原始供应商错误。
- 错误/取消清空连续偏差证据；账号在检测期间被移除时，不再因访问空账号导致结果处理异常。
- 已完成样本保留哈希、长度、用量和耗时。旧历史字段缺失时不补造诊断，失败请求不自动重试。

## 安装与验收边界

Linux 附件为 `Es2API-linux-x64-20261104-r2.tar.gz` 和对应 `.sha256`。按 [Linux 运维说明](../deploy-linux/README.md)备份升级，保留完整账号数据、固定出口和加密密钥。

本版重新编译前端与嵌入界面的 Windows/Linux Go 程序；执行 Kernel、CLI/bwrap 工具沿用已固定的版本。仅做语法、类型、编译及产物核对，未运行测试套件、浏览器验收、Linux部署或真实供应商推理。历史 ModelTrace 第三样本502仍未闭环，真实 Codex CLI→API与跨账号隔离仍未验收。

详见 [ModelTrace](MODELTRACE.md)、[CLI 能力与边界](CODEX_CLI_BACKEND.md)及[已知限制](KNOWN_LIMITATIONS.md)。
