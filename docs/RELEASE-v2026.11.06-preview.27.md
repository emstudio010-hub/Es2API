# Es2API v2026.11.06-preview.27

## 工作区凭据恢复

- 具体账号池工作区显示凭据恢复状态、最近同步时间和同步入口；状态是控制面最近一次保存的快照，不是实时监控。
- 区分“恢复实例”与“恢复已保存凭据”。待恢复时禁用启动、实例恢复、重建、删除和配置编辑；同步/停止仍可用。存在在途请求或凭据交接时拒绝凭据恢复。
- 管理员 POST /api/v1/admin/accounts/:id/recover-credential 经 Go 白名单和私有管理认证转发，先暂停调度并返回202，页面轮询最终状态。202只表示已受理。
- VM2在同一控制锁内严格核对canonical槽ID、账号、代次、独占固定出口、执行后端，以及日志与控制面原供应商身份索引；响应归属也来自锁内已核对记录，不返回token或身份索引。
- 恢复仅提交本机加密保存的响应，不再次消费refresh token，不调用模型，不自动启动或恢复调度。仅prepared、不完整、身份/快照不符等继续保留并拒绝。恢复成功后，原有“删除待确认”标记仍保留，不能误开启调度。
- 导入ifMissing重试已有槽时比较双方历史验签身份，而不是只比较共享workspace提示；不覆盖已有凭据。
